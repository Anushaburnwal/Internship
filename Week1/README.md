# Week 1 HTML Basics Practice

This project contains a small static webpage set for the Week 1 HTML practice assignment.

## Files

- `index.html` – home page with the assignment topics and practice questions
- `page2.html` – student marks table
- `page3.html` – registration form
- `styles.css` – shared styling for all pages

## Run locally

From the project folder, start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

This will show the homepage with navigation links to the other pages.
